# 自瞄链路复核

本次检查 `codex/relative-aim-restart` 的检测/PnP、坐标变换、共享车体、匿名切板、时间传播、弹道、许可、原生 GUI 和仿真实际发弹。实施起点为视觉 `d4e1760`；配套仿真为 `112ce4eae62fb308af064ef9175b04c33b8c1cbc`，未修改其源码、配置或接口。

**结论：自动回归 10/10、仿真侧相关回归 4/4、九种运动组合的 HP 功能闭环 9/9 通过。不能据此认定运动目标精度已全部通过。** 渲染图像下的平移场景仍有约 0.18–0.22 m 车心水平 RMSE，且存在启动/重建轨离群与变速旋转误差。当前结果解决持续 HOLD 和模型不可见等可复现问题，尚不能签署“所有模型精度问题已修复”或实车验收结论。

## 修改与原因

算法的当前定义由 [tracker README](../../src/rm_tracker/README.md#数据流与算法)维护；本节记录这次变更及验证，而非另立算法规范。

| 位置 | 具体变化、原因和影响 | 验证状态 |
|---|---|---|
| `body_ekf.cpp` 关联 | 四板逐一比较原 yaw、视线镜像及各自 π 翻转；实际更新使用选中的同一个 yaw。重复分配不重复融合，导出匹配掩码和拒绝原因，避免切板时错误观测分支进入状态 | 带噪/乱序/重复/离群回归通过 |
| `tracker.cpp` 建轨 | 按三维距离选初始板；用观测与几何先验的雅可比初始化交叉协方差，保留启动镜像候选并累计似然选解。单块静止板不能唯一确定车心，不能靠错误独立先验制造确定性 | 初始化板协方差检查及静止单板回归通过；渲染图像仍有错误建轨样本 |
| `body_ekf.cpp` 噪声 | 增加沿视线的测深方差；到达协方差包含未来过程噪声。修正原先用当前 P 代替未来 P 的过度确定性 | R 方向性、零值兼容、未来 P 增长回归通过 |
| `tracker.cpp` 状态/SPIN | 建轨/失锁用有效关联累计时间；无效帧清除旧匹配及瞄准缓存。SPIN 使用共享体角速度及持续时间，旧单板辅助估计退出实际 SPIN 门控 | 零 dt、断流、漏帧禁发及集成回归通过 |
| `tracker.cpp` 选板 | 到达时刻枚举实际四板，使用 0.08 rad 切板惩罚；没有半径/高度组交换，没有换板冷却或冻结车心。用近表面距离估飞行时间，再检查实际枪口飞行时间的一致性 | 四板物理位置及带噪切板回归通过 |
| `tracker.cpp` HOLD | 完整几何未收敛不再一律禁发；至少 8 次接受更新后，按选中板未来切向/竖直不确定度、当前匹配、状态和弹道等条件判断。静止单板的未观测半径不应永久阻止已能确定的板位置发射 | 单板 `body_ready=false` 下仍有有效许可；九项 HP 实际发弹通过 |
| `tracker.cpp` 角窗 | 去掉远距离 pitch 1° 下限；物理板窗同时受配置 yaw 上限约束；HUD 不再改写配置。这避免远处板窗被放大和配置失效 | 8 m / 0.5° pitch 拒绝、0.01° yaw 配置及不变性回归通过 |
| `rm_tf_tools.cpp`、两个入口 | 使用已有 PnP 法线的完整旋转再取水平朝向，避免只相减 yaw 丢失俯仰关系。ROS `ArmorInfo` 原本就有法线字段，本次未新增消息。原生输出追加观测法线；零/无效法线回退旧角度。ROS 入口补齐无效深度/非有限观测拒绝，与原生入口一致 | 共用核心倾斜姿态回归通过；ROS 节点编译/运行未验证 |
| detector/PnP | 灯条中线端点保留浮点精度；不足两个像素的采样长度拒绝，避免单点采样除零。灯条尺寸改为正有限配置，并在相机标定刷新时保留。默认尺寸保留原 135/58 mm；ROS 运行时改尺寸明确拒绝，避免参数表变了而实际未更新 | 配置尺寸实际 PnP、标定刷新、畸变/主点及非法参数检查通过；ROS 适配与有效硬件光学尺寸未验证 |
| 步兵 YAML/参数加载 | 根据带噪回归降低刚性几何游走与过程噪声，加入可关闭的测深噪声。显式列出 `system_delay`、`controller_delay`，0 表示不补偿；当前数值不是测得的硬件延迟。ROS Q 默认值改为引用共用核心字段 | 实际 YAML 切板回归及零补偿 tracker 集成通过；实车延迟未验证 |
| 原生 GUI | 跟踪图画估计车心、四板、匹配/选中标记；弹道 HUD 输出 HOLD 原因和到达标准差；默认四格包含跟踪图。模型板为名义竖直板，非倾斜 CAD 真值投影 | 九项均生成四板模型，无窗口错误；已检查保存图像 |
| 测试/工具/文档 | 新增实际 YAML 的噪声切板测试、固定日志回放和离线真值评分工具；同步 tracker、detector、消息和 standalone 文档，纠正“ROS 无法线”与旧默认图描述 | 构建和相关自动检查通过；原始日志/图像留本机 |

时间修复本身已在起点提交中：正 dt 不截断，重复/倒序/非有限戳拒绝，超过 0.5 s 断流重建。此次重新覆盖真实 dt、Q 离散化、PSD/Joseph、雅可比、离群不改状态和加速模型，不把旧提交的代码重复列为本次新增。

## 验证方法和判据

1. 数值与集成：先查既有模型缺陷，再用对应回归检查关联、协方差、时间、物理四板和许可条件。理想/带噪输入与真实 RGB 分开评价；不以编译成功代替行为通过。
2. 固定输入对照：保持 `live-20261029-174831` 的三个场景观测角点、K/D、姿态和时间不变，分别重新 PnP 并送入同一 tracker。比较原 135/58 mm、CAD 边界推得 125.8/59.47 mm、完整法线以及重投影误差评分试改。CAD 与重投影试改均未稳定降低车心误差，因此未采用。没有继续用随机参数搜索掩盖缺口。
3. 实际闭环：真实渲染 RGB → 灯条/分类/PnP → tracker → 原生结果 → 既有仿真门控 → 实际弹丸 → HP。九种组合为平移 stationary/constant/sine × 旋转 off/constant/sine；每项 20 仿真秒，seed 42，350 HP，开启装甲判伤。恒速平移设定 1.5 m/s、振幅 2 m，恒速转动 1 rps，正弦转动偏置 1、幅值 0.5 rps、周期 8 s；具体运动限幅和启动坡度由未修改的仿真执行。
4. 功能判据：每项至少 2 次实际发弹且 HP < 350，主机/视觉正常退出，四板模型曾输出，窗口错误为 0；许可不得绕过当前匹配、TRACKING、有效弹道与空阻断列表。该最低功能线是此次检查脚本的工程判据，**不是用户确认的命中率或模型精度标准**。
5. 真值评分：只在离线工具读取敌方真值，按同 generation 最近时间（≤20 ms）对齐；车心只比水平位置，板位置与最近物理板比三维距离。统计 TRACKING 且本帧匹配的所有帧，包括启动和重建轨；没有删掉大误差样本。`fire_*` 只筛视觉许可帧，并不等于实际出膛帧或命中误差；yaw 最佳分支统计还条件化于原始位置误差 <0.1 m，不是无条件姿态精度。

单块静止板的车心不可观测，允许其车心误差较大，同时必须验证板本身可瞄准。合成运动测试的车心判据为 RMSE <0.06 m、最大 <0.15 m；不能把合成数据的标准已通过外推为渲染图像也通过。

## 执行证据

最终完整原生运行目录：`live-20261029-180906/`。逐项帧数、实际发弹、HP、阻断原因和退出状态见 [checks](final/checks.json)，紧凑结果见 [summary.csv](final/summary.csv)。九项合计 8,931 帧、142 次实际发弹，非法许可帧和窗口错误均为 0。HP 归零后的后续无目标帧仍保留在总帧数中，不能把总帧数直接用作有效可见目标跟踪率分母。弹丸 `hit_count` 会累计多次接触，不能解释为独立命中发数或据此算命中率。

自动结果见 [视觉 CTest](ctest-final.xml)、[仿真 CTest](sim-ctest-final.xml)。数值统计见 [Body EKF](final/body-summary.txt)、[实际 tracker](final/tracker-summary.txt)、[实际 YAML 噪声切板](final/noisy-switch-summary.csv)。其中最强噪声切板的车心 RMSE 0.01616 m、最大 0.05301 m，合成测试通过；静止单板另有 1,307 个完整几何未收敛时的许可帧。

真实图像的结果见 [真值统计](final/truth-summary.csv)及各场景 `truth-*.json`。原地恒转车心 RMSE 约 0.056 m；六种平移组合约 0.18–0.22 m，最大误差仍可达约 0.96 m。由此只能判定当前功能恢复，不能判定车心/姿态精度全面合格。部分场景只有 2 发，不能称为稳定命中率已经达到要求。软件允许发射并不保证模型偏差下的命中。

实际运行文件与配置校验值见 [identities](final/identities.json)。已将本轮验证的 EXE/DLL 成对更新到仿真默认的 `build/native/bin/`，旧文件留本机 `previous-native-bin/`；部署后校验值与默认启动检查分别见 [部署身份](final/deployed-identities.json)、[默认启动检查](final/default-launch-checks.json)。源码版本身份见 [source-identities](final/source-identities.json)。

固定输入对照统计留在 `comparisons/`；对应原始回放留本机 `normal-*`、`pixel-*`、`fixture-*` 目录。GUI 保存图在每项 `vision/frame_*/` 下，已检查 `stationary_constant/vision/frame_g0_r2_n113_t1.287000/tracking_state_img.png` 等图像，确认车心、四板和文字已画出。

补充静态光学诊断：用 stationary/off 首次观测起 0.6 s 的 19 次观测，将畸变校正后的角点射线与已有 15° 倾斜板平面直接相交，得到有效端点间距中位数 130.28 / 57.13 mm，见 [optical-fixture](final/optical-fixture.json)。该静态尺寸用于另三个运动场景的固定角点回放，车心 RMSE 分别降到约 0.019 / 0.147 / 0.169 m，但恒速平移恒速旋转的角速度 RMSE 变大、有效匹配减少，因此也未替换默认参数。它支持“有效光学端点与 CAD 外壳不同”的解释，尚不足以证明所有偏差都源自尺寸。诊断工具只接受静止真值，不在线运行；这一小段仿真夹具不能冒充完整硬件标定。

## 复现

在 DT46-V 根目录执行（现有依赖安装路径由仿真本机 profile 管理）：

```powershell
. ../.local/runtime-path-check/activate.ps1
$env:PATH="$pwd/build/aim-validation-full/standalone;"+$env:PATH
cmake --build build/aim-validation-full -j 6
ctest --test-dir build/aim-validation-full --output-on-failure
& outputs/aim_model_validation_20261029/run-cases.ps1 -Gui
```

新建构建目录的依赖/配置方式见 [standalone 构建说明](../../standalone/README.md#构建)。`run-cases.ps1` 从现有会话与裁判配置生成输出目录内的实验副本，不修改仿真配置；正常结束和失败均清理本次进程。

固定角点回放示例（保持原始输入，不能拿此工具代替实际出膛检查）：

```powershell
build/aim-validation-full/dt46_tracker_log_check.exe <frames.jsonl> src/rm_tracker/config/tracker_params_infantry.yaml <replay-dir> .02 .02 .5 135 58
build/aim-validation-full/dt46_aim_truth_check.exe <frames.jsonl-or-replayed.jsonl> <truth.jsonl> <score-dir>
build/aim-validation-full/dt46_armor_geometry_check.exe <stationary-frames.jsonl> <stationary-truth.jsonl> <fixture.json>
```

## 适用边界、偏离和未完成项

- 没有扩展 MCU 字段、敌方在线真值或本车绝对平移输入；原生适配器原本存在的完美光学旋转/枪口元数据仍被保留。因此本次是该原生接口下的软件回归，不能称为实车输入公平验证。更早独立视觉 IMU 的实验没有替换当前原生入口。
- ROS 法线字段与检测发布代码已核实；共用变换函数已测试，但 Windows 没有完成 ROS 2 Humble 节点编译和 rqt/串口/实车测试。这些必须标为未验证。
- 偏离原候选方案：实验证据否定直接采用 CAD 灯条尺寸和本次重投影打分试改，均已撤回；保留原默认尺寸。源码仍可按真实有效灯条尺寸配置，但不能用 CAD 外壳边界冒充测得的发光端点。
- 未完成：渲染图像下的测深偏差、重建轨大误差及变速旋转估计仍需继续定位。仅靠当前高斯 P 门控不能消除这些模型偏差；不降低验收口径来宣称全部精度通过。测试进程已关闭，未推送、未合并其他分支。

此前开源实现查阅与同输入基线证据由 [上一阶段报告](../body_model_repair_20261029/report.md)维护；本轮不把未核对版本的网上项目当成已实现的功能。
