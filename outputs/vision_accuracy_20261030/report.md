# 5 m 静止命中与运动预测诊断

基线 `f81260c`，实验分支 `codex/vision-five-meter-accuracy`。本轮目标是解释 5 m 静止偏弹，再分离平移和旋转，采用有闭环收益的简单调整。ROS、实车仍属后续阶段。

## 结论与实际变更

1. **5 m 静止的主要损失是发射角散布。** 原参数三组种子的成熟弹丸为 190/512 有效命中；只关闭角度散布、保留弹速波动后为 487/487。不能据原命中比例认定弹道或 PnP 大错。原发射散布没有被改小，零散布只存在于诊断场景。
2. **实际改动只有步兵两个噪声参数。** `ekf_QR_q_xyz` 从 0.1 改为 0.3，`ekf_QR_r_xyz_factor` 从 0.5 改为 0.05。5 m 时基础观测 sigma 由约 30 mm 降至 7.5 mm，独立测深噪声保留。固定输入的横向观测误差 P95 约 2 mm，原参数导致明显速度滞后。运行期状态维数、计算路径、发弹门槛、弹道公式均未增加或放宽。
3. **修正文档与现有实现不一致之处。** tracker 说明修复破损强调标记、过时的“改弹速重建弹道表”注释，并链接本次证据；standalone 删除“适配层再次算弹道”的过时描述，说明直接读取当帧缓存。源码此前已这样实现，本次没有改变接口。
4. **补齐离线诊断和复现脚本。** 保留散布开关、种子、参数覆盖、固定图像回放、逐发误差、分段统计与绘图。在线视觉不读取目标真值。

默认原生程序与本次测试的 EXE/DLL 哈希相同，本轮无需重建或替换二进制；下一次启动会读取已更新 YAML。已有进程不会自动热加载这两个参数。

## 方法与统计口径

- 每例 20 s，实渲染 RGB → 检测/PnP → Tracker → 云台/发射 → 裁判扣血。只有装甲伤害规则启用，目标 HP 提高以避免死亡中断。每发以裁判接受的唯一 `shot_id` 计数，不把反弹或其他碰撞计为命中。
- 标称 5 m 是车辆初始位置间距；枪口到近侧板约 4.54 m。原发射器在 yaw/pitch 各有均匀 ±1.5° 扰动，横向/竖直覆盖约 ±119 mm，明显大于 135×125 mm 板面。子弹直径 17 mm，判定还涉及碰撞代理和半径余量。
- 先用种子 42/43/44 对照原角度散布与零角度散布。随后平移、旋转、组合分别隔离；平移沿 X、最高 1.5 m/s、最大加速度 4 m/s²，端点前刹车并反向，半周期约 1.375 s。不是全程匀速。旋转为 1 rps。
- 静止逐发从实际 `muzzle_exit` 的位置/速度，用独立 RK4（0.5 ms）积分重力与平方阻力到板面。真值板心 site 位于局部 z=1.8 mm，实际前表面为 1.6 mm，已修正这 0.2 mm 差值。仿真结束时仍在飞行的弹丸不计失败。
- 运动表采用统一保守窗口：发射时刻早于 19.65 s 的弹丸计入成熟样本。有效命中/秒另按完整 20 s 内已产生的有效伤害计数；包括末尾已命中的弹丸。
- 静止、纯旋转之外的逐发方向诊断只对不旋转平移实现；没有把静止平面积分误套到旋转板。后者只统计真实裁判结果。
- 固定图像回放以同一份真实观测比较参数；预测 horizon 固定 0.23 s（约飞行 0.20 s + 配置补偿 0.03 s），只用于离线归因。最终收益由完整闭环验证，不能把回放许可直接当成新命中。

## 闭环结果

“调整后”均指最终 `q=0.3 / r_factor=0.05`。目录名含 `responsive`、`final-spread` 的运行是中途 `q=0.5` 候选，不能冒充最终结果；每例实际生效值记录在 [summary.json](summary.json) 的 `q_xyz/r_xyz_factor` 字段。

| 场景 | 种子 | 原参数：成熟有效命中/发射 | 调整后：成熟有效命中/发射 | 原参数 → 调整后，有效命中/秒 |
|---|---|---:|---:|---:|
| 零角散布，静止 | 42 | 160/160 | 160/160 | 8.00 → 8.00 |
| 零角散布，纯平移 | 42、43 | 66/228 | 94/259 | 1.675 → 2.400 |
| 零角散布，平移加旋转 | 42、43 | 52/202 | 69/186 | 1.300 → 1.750 |
| 零角散布，纯旋转 | 42、43 | 171/172 | 158/158 | 4.325 → 4.000 |
| 原角散布，纯平移 | 42 | 19/133 | 28/149 | 0.95 → 1.45 |
| 原角散布，平移加旋转 | 42 | 9/107 | 17/107 | 0.45 → 0.85 |
| 原角散布，静止 | 42 | 63/170 | 65/169 | 3.15 → 3.25 |

这是一项取舍：平移和组合运动的有效伤害吞吐提高，纯旋转有效命中吞吐下降约 7.5%；不能声称所有场景都变好。最后一项静止差异很小，只有一组种子，不作为提升结论。真实闭环受异步采图/调度影响，相同种子不保证相同图像和发射时刻；小样本不能外推为稳定概率或实车结果。

## 偏弹发生在哪里

- 同一份日志、双方均有效跟踪的相同 876 帧比较，预测横向误差 P95 从 314 mm 降至 179 mm。共同匀速段 285 帧为 199 → 61 mm；共同转向段 591 帧为 320 → 181 mm，见 [paired-replay-summary.json](paired-replay-summary.json)。
- 真实逐发分析用执行日志找到发射时实际采用的图像帧，再分离目标预测方向与实际弹丸方向。纯平移两组最终运行，执行方向造成的横向误差 P95 约 2.1–2.2 mm；主要损失在目标预测，不能归因于云台没有执行指令。
- 纯平移的成熟匀速样本从 52/61 命中提高至 66/69；转向段从 14/167 提高至 28/190，仍很差，见[逐发分段统计](shot-phase-summary.json)。即使把真实当前位置/速度交给理想匀速预测，转向时 0.23 s 预测误差 P95 也约 105 mm；现有速度估计还会进一步滞后。继续只调参数或缩小开火窗口无法根治这个模型偏差。
- 静止原参数的 PnP 深度仍有约 +89 mm 均值偏差，横向误差却很小；关角散布后实际弹道落点集中在板内。这个单视角结果不能代表跨视角深度问题已解决。
- 静止种子 43 的第 131 发最初处于独立自由飞行矩形边界内；按仿真实际接触点、入射速度和前板面复核，其投影竖向越过带半径余量的边界约 0.18 mm。已归为代理判定边界外，当前全部静止未命中均有对应解释，没有通过改动仿真判定“修复”它。

## 验证与边界

- 34 个完整闭环场景均通过冒烟约束：正常退出、有有效伤害、0 个无效发弹许可、0 个窗口错误。逐例数据见 [summary.json](summary.json)，汇总及二进制/配置哈希见 [validation.json](validation.json)。
- 原生 12 项检查最终全部通过：完整一轮先有 11 项通过，噪声切板回归暴露 `q=0.5/r=0.05` 的车心峰值 153 mm 超过原有 150 mm 上限；`q=0.4` 仍为 150.1 mm。最终 `q=0.3` 为 133.7 mm，单独重跑该项通过，未修改任何断言或放宽验收线。[最终回归统计](accepted-switch-summary.csv)。
- 本轮没有新增在线算法、MuJoCo 依赖或运行期搜索。保留上一轮直接弹道；MuJoCo 离线对照的证据仍由[速度与弹道报告](../vision_speed_20261030/report.md)维护。本轮未重新测量视觉时延上限，不宣称新的速度提升。
- 尚未解决：急刹反向的预测偏差、旋转吞吐取舍、PnP 跨视角深度偏差。多车身份、遮挡/残缺板、ROS 和实车未在本轮验证。下一步应围绕刹车反向的预测及其不确定度做一项独立验证，而不是继续堆门控条件。
- 方案内完成误差拆分和低成本参数调整，没有改变已确认范围。共享车心、两组半径和高度差估计维持原实现，定义见 [tracker 数据流](../../src/rm_tracker/README.md#数据流与算法)。根 README 仍有旧九维/查表概述，本轮只同步负责当前算法和接口的文档。

## 复现

在视觉仓库根目录，使用项目已有 runtime 激活脚本及原生 Release 构建。Python 诊断需要 NumPy，绘图另需 Matplotlib。本机绘图依赖仅安装于忽略的 `.cache/vision-accuracy-plot`，没有修改项目运行依赖。

```powershell
# 当前参数，真实闭环；每次自动创建独立目录。
& outputs/vision_accuracy_20261030/run-cases.ps1 -Batch repeat -Cases 5_off,5_constant -Translation constant -AngleSpread 0 -Seed 42
# 恢复原角散布复核。
& outputs/vision_accuracy_20261030/run-cases.ps1 -Batch repeat-spread -Cases 5_off,5_constant -Translation constant -AngleSpread 1.5 -Seed 42
# 同一份已生成的观测回放；输出也含可交给 run-cases.ps1 -Parameters 的覆盖文件。
& outputs/vision_accuracy_20261030/replay-cases.ps1 -Frames <run>/vision/frames.jsonl -Candidates baseline,q03
python outputs/vision_accuracy_20261030/analyze.py
python outputs/vision_accuracy_20261030/shot-motion.py <translation-run>
python outputs/vision_accuracy_20261030/motion-errors.py <translation-run> --frames <replay>/replayed.jsonl --output <replay>
ctest --test-dir build/aim-validation-full --output-on-failure
```

原始 events/states/actions/frames/truth、逐发 CSV、图片及二进制留本机；入库本报告、复现脚本与紧凑统计。`plot-errors.py` 针对本次固定目录绘图，重跑到新目录时须对应修改输入路径。
