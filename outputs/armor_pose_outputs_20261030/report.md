# 固定权重的测试集输出核对

本次按已确认的[独立预测与固定计算契约](../../../tools/armor_dataset/README.md#输出和固定计算)，检查首版网络的最终结果是否与仿真真值一致。模型、损失、训练清单、权重及存在性阈值均未调整，也未用测试结果选择模型。

核对源码及实际 ONNX 输出名后确认：只有装甲存在性、贴纸、阵营、三维位置和 6D 旋转五组网络输出，没有独立的深度、直线距离或偏角头。位置头的内部表示由[训练说明](../../tools/armor_pose_training/README.md#模型与边界)维护；不能把内部 log(Z) 解码说成新增的深度预测头，也不能把派生字段单列评分说成新增训练目标。本次全部 1,122 条预测均核验了深度等于位置的 Z 分量。

## 数据与方法

- 固定验证集选出的第 18 轮 `best.pt`，运行其既有 CPU ONNX；训练过程见[首轮运行记录](../armor_pose_training_20261030/report.md)。
- 独立 test 集：1,122 张裁图，886 张正样本、236 张负样本；贴纸评分 886 张，阵营评分 884 张，其余 2 张正样本未开放阵营监督。
- 输入仅为图片和裁剪相机 K/D；真值用于事后评分。沿用原 scene_group 划分，没有重划测试集。
- 存在性阈值沿用 0.5；分类按 argmax。连续量报告误差，不擅自设置“正确”的验收阈值。
- 位姿评分包含全部 886 张有位姿监督的正样本，也包含被存在性头漏检的样本。本次退化旋转为 0。
- 假设与判据：CPU 导出应保留原模型输出语义，逐输出与 PyTorch CPU 比较，沿用导出时 `atol=rtol=1e-4`；派生量应服从同一份位姿的固定公式。识别准确度是否够用，由实测误差判断，不预设通过。

精确模型、清单 SHA-256、导出一致性和完整分层统计见 [summary.json](summary.json)。

| 独立识别项 | 对上真值 | 正确率 |

| 是否装甲 | 1,112 / 1,122 | 99.11% |
| 贴纸类别 | 764 / 886 | 86.23% |

| 是否装甲、贴纸、阵营全部正确（有完整分类监督的正样本） | 758 / 884 | 85.75% |

存在性：TP 883、TN 229、误检 7、漏检 3；负样本误检率 7/236 = 2.97%，正样本漏检率 3/886 = 0.34%。贴纸与阵营准确率分别统计，不用存在性门控剔除错误样本。

三维位置 RMSE 为 0.7722 m，完整旋转平均误差为 31.105°。深度有符号均值为 +0.0222 m，但它会抵消不同距离下的正负误差，不能据此声称深度只差约 2 cm。板面斜视角有符号平均误差为 −21.724°，说明这批测试中估计整体偏向正对相机；这里是误差现象，尚未做成因实验。

分类已有可用的初始结果，位姿及其派生量仍有较大误差。这次没有同输入 PnP 对照，不能据此宣称已经可以替换 PnP。

## 检查与复现

在视觉仓库根目录执行：

```powershell
.cache/armor-training-env/Scripts/python.exe outputs/armor_pose_outputs_20261030/inspect_outputs.py
```

脚本读取首轮 `.cache/armor-pose-runs/bootstrap_20261030` 的已保存权重和 ONNX，以及父仓库 `outputs/armor_batch_20261030/dataset_10000/training/training.jsonl`；只重建本目录的核对产物，不训练或改写权重。

已验证：1,122 张图片路径唯一且来自 test；ONNX 实际输出名符合五组约定；全部测试图的 ORT CPU 与 PyTorch CPU 输出通过原有 `1e-4` 一致性容差。三维位置最大逐分量差为 0.00001240 m。预览图已目视检查；HTML 脚本通过语法、筛选计数、误差排序和翻页逻辑检查，尚未做真实浏览器布局检查。

最初额外要求 CPU 深度中位数与历史 GPU 汇总相差小于 `1e-5 m` 的检查失败：实际相差 +0.0003972 m，P95 相差 −0.0011632 m。随后按原导出验证口径对全部测试图进行 CPU PyTorch/ORT 逐输出检查并通过。分类计数与历史 GPU 结果一致，本文连续误差采用实际 CPU 数字；没有把 GPU 汇总差异强行写成零，也未据此调整权重。GPU 与 CPU 差异的具体底层运算来源未进一步定位。

本次变更：补齐可复现逐图核对脚本与统计，澄清训练说明中独立预测和派生项的关系；模型及线上逻辑没有改动。先前将 log(Z) 内部表示直接判为“偏离方案、需要重做权重”的口头判断已更正，未实施该变更。

未验证：完整帧候选提取后的检测效果、同输入 PnP 对比、线上部署精度；本任务限于仿真裁图。测试集只用于本次固定模型的结果核对，后续训练调参仍使用训练/验证集合。
