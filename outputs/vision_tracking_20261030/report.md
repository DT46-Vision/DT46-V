# 仿真视觉追踪、几何估计与发弹优化

2026-10-30，视觉分支 `codex/vision-tracking-closure`，起点 `3eb0f24`。仿真保持 `e704b11`，只生成实验场景副本；没有修改仿真核心，也没有向视觉增加目标真值。已有光学/枪口姿态输入继续使用。ROS 与实车是后续阶段，本次验收对象是渲染 RGB 到实际发弹、裁判扣血的仿真链路。

## 结果

最终 6 场固定位置静止/旋转测试各 12 s、3 场横移测试各 15 s，均发弹且出现有效扣血；无无效许可、无窗口错误，进程正常退出。11 项 CTest 通过，见 [ctest.log](ctest.log)。这是功能闭环通过，不能解读为全部场景已稳定命中：5 m 横移加旋转仍只有 2 / 34 发造成扣血。

固定位置四场对照如下。车心误差为所有 TRACKING/TEMP_LOST 帧的水平 RMSE，包括短时漏配帧；不把板高状态当底盘中心高度。有效命中按 referee 接受的 `armor_judgement` 去重 `shot_id`，不使用可重复接触的 `projectiles.hit_count`。

| 场景 | 修改前发弹 / 有效命中 | 最终发弹 / 有效命中 | 车心 RMSE：前 → 后 |
|---|---:|---:|---:|
| 3 m 静止 | 39 / 39 | 75 / 75 | 13.9 → 9.9 cm |
| 5 m 静止 | 0 / 0 | 83 / 29 | 18.2 → 12.1 cm |
| 3 m 匀速旋转 | 0 / 0 | 40 / 33 | 15.5 → 5.6 cm |
| 5 m 匀速旋转 | 0 / 0 | 39 / 17 | 46.2 → 23.6 cm |

另外，1.4 m 静止为 67 / 67，匀速旋转为 11 / 9。横移使用正弦模式、幅度 0.75 m、配置速度 1.5 m/s；3 m 不旋转为 50 / 11，3 m 旋转为 49 / 9，5 m 旋转为 34 / 2。后两项不能称为高精度运动命中。

完整逐场门控、耗时、误差分位数和阶段对照见 [comparison.json](comparison.json)。图像由实际闭环产生，GUI 调度与处理帧数不同，因此这些闭环不是逐帧相同输入的严格消融，也不据此声称每一帧改善。原始日志、截图和二进制留在本目录的运行子目录；入库统计和复现脚本。

## 逐项变化、原因与验证

1. **发弹门控**（`tracker.cpp`、参数及原生适配）：删除 SPIN 必须几乎正对的额外弧长门槛，删除横/竖两个独立的 2-sigma 半板限制。改用视线坐标下的投影板面和当前瞄准误差，计算近似高斯落板概率；步兵门槛为 0.25。仍须有当帧匹配、TRACKING、足够更新次数、有效弹道、预测一致性、射程和实际板面角窗。JSON 输出 `aim_hit_probability`。依据是 5 m 静止基线连续 TRACKING 却全被不确定度拒绝，3 m 旋转还叠加正对门槛。最终此前零发弹的三场均扣血；回归确认背面、越界弹道、无匹配与错误时间不能发射。
2. **几何估计与去冗余**（`tracker.hpp/cpp`）：删除按 ID 写入半径的表，以及旧单板滤波、圆拟合、冻结车心、换板周期等重复路径。本轮运行代码净减少 719 行。两组独立半径和有符号高差仍在线估计，只用通用范围中点/零作初值；输出板位置和速度统一从共享车体求出。相同观测不同 ID 得到相同初值。半径、高差仍有模型范围保护，不是无界估计。当前能力与可观测性由 [tracker 说明](../../src/rm_tracker/README.md)维护。
3. **白字和多板配对**（`detector.cpp`、检测配置）：红蓝强度比改为 1.3；已确认配对占用实际灯条及二维板面，取代占用整个横向区间。保存失败帧中假白字被剔除，真灯保留；灰度反例没有灯；上下分离但横向重叠的板能同时检出，交叉候选仍拒绝。仍支持同车多板观测，不等于已实现多车独立跟踪。
4. **端点与姿态解算**（`detector.cpp`、`pnp.cpp`）：局部半对比度插值修正像素中心造成的灯条缩短。原生步兵复用相机姿态，使用配置的装甲安装倾角直接解四点位置与 yaw；先解线性位置/正余弦，再归一化朝向并解平移，没有逐角搜索或历史法线强行改写。尺寸仍为配置的灯距/灯高；不输入车心、半径或组间高差。亚像素合成边界回归通过；1.4/3/5 m、板朝向和相机滚转/俯仰组合的前向投影回归通过。实际闭环旋转车心误差下降，但远距离测深和像素定位仍有偏差。
5. **运动关联**（`body_ekf.cpp`、步兵配置）：额外深度噪声启用时，视线方向硬门槛与其 3-sigma 一致，横向仍用原门槛，然后执行 NIS 关联；修复“R 允许但先被固定 20 cm 拒绝”的矛盾。平移过程噪声由 0.02 改为 0.1，改善横移响应。新增回归确认径向容差不放宽横向离群门槛。首次 5 m 运动闭环 1 发 / 0 命中、跟踪 99 / 468 帧，最终为 34 发 / 2 命中、跟踪 372 / 507 帧；恢复功能，但精度未达稳定命中。
6. **证据与评分**（`tools/check_aim_truth.cpp`、`check_pnp.cpp`、本目录脚本）：原评分以被评分的三维测深结果找最近真值板，可能误配侧板。原始姿态现按可见面和图像方向匹配；车心评分增加包含 TEMP_LOST 的口径。旧近邻镜像最小误差指标保留为诊断，不能代表原始 PnP 精度。当前文档在各包 README 同步，历史报告未改写。

## 半径和高差是否写死

不是固定参数。状态中 `rA/rB/hB` 接受观测更新，允许两组半径不同、B 组高于或低于 A 组。新合成回归从共同先验开始，含位置/角度噪声；最终：

| 真值 rA / rB / hB（m） | 估计（m） |
|---|---|
| 0.17 / 0.37 / 0.14 | 0.170453 / 0.370428 / 0.139511 |
| 0.37 / 0.17 / −0.14 | 0.370257 / 0.169254 / −0.139836 |
| 0.25 / 0.25 / 0 | 0.250255 / 0.250163 / −0.000730 |

既有噪声模型测试水平车心 RMSE 1.45 mm，见 [body-geometry-summary.txt](body-geometry-summary.txt)；这是理想观测层测试，不能替代上述 RGB 闭环的厘米级误差。单块静止板无法唯一辨识真实半径和车心，多角度/多板观测才提供额外约束。安装倾角、灯距和灯高是另一类物理先验，与车体半径/对角组高差不同；当前倾角约束的适用边界见 [detector 说明](../../src/rm_detector/README.md#处理流程)。

## 实验过程与未采用方案

- 初始远距离布置移动了观察车，使相机撞入场景边界；截图确认后排除 `baseline-20261030-005135` 中 3/5 m 样本，后续固定观察车、移动靶车。有效基线为 `baseline-open-20261030-005458`。
- 单独按已知倾角在两个 IPPE 候选中挑选，对旋转改善不足；没有作为最终算法。直接倾角解在固定原角点日志中改善姿态，但测深仍受角点偏差影响，随后加入端点插值并用完整闭环验证。阶段结果保存在 `gate-color-*`、`upright-edge-*`，不隐藏中间退步。
- 横移回放比较 q=0.02/0.1/0.2/0.5，详见 [motion-replay-summary.json](motion-replay-summary.json)。较大 q 能改善响应但增大预测不确定度，并非越大越好；最终使用 0.1 和显式概率门槛。回放保持图像观测和相机运动，不能模拟新控制量对后续画面的反馈，因此最终结论仍依赖闭环。
- 仿真保留原 ±1.5° 方向散布及弹速随机性。5 m 静止靶在首个车体接触处的横/竖标准差约 6.6 cm；该统计仅包含接触车体的弹丸。没有为通过实验关闭散布，也不能把所有未命中都归咎于视觉或散布中的单一因素。
- 完整算法处理时间在最终各固定位置场景中位数约 3.0–3.9 ms，基线四场约 10.3–14.1 ms；受场景帧序列与 GUI 调度影响。固定失败帧检测基准中位数 0.659 ms、P95 0.830 ms，见 [detector-benchmark.txt](detector-benchmark.txt)。它使用回归的宽松颜色参数，不冒充全系统实时周期保证。

## 复现与交付

先在视觉根目录激活 `../.local/runtime-path-check/activate.ps1`，将 `build/aim-validation-full/standalone` 加入 PATH。

```powershell
cmake --build build/aim-validation-full --target dt46_vision dt46_body_ekf_check dt46_tracker_model_check dt46_tracker_switch_check dt46_detector_check dt46_core_check dt46_pipeline_check dt46_aim_truth_check --parallel 4
ctest --test-dir build/aim-validation-full --output-on-failure
outputs/vision_tracking_20261030/run-cases.ps1 -Batch repeat -Seconds 12 -Gui
outputs/vision_tracking_20261030/run-cases.ps1 -Batch repeat-motion -Cases 3_off,3_constant,5_constant -Translation sine -Seconds 15 -Gui
```

[summarize.py](summarize.py) 对记录的批次离线评分；复跑后将其批次列表替换为新目录名。全分辨率 RGB、K/D、光学变换和目标真值分别记录，真值只在离线评分时读取。`run-cases.ps1` 的通过条件是发弹 ≥2、靶车扣血、有效门控与进程检查通过，不包含高命中率要求。

已把本次验证构建的 EXE/DLL 更新到默认 `build/native/bin`，两处 SHA256 一致，见 [binary-identities.json](binary-identities.json)。旧默认二进制留在 `build/native/backup-vision-tracking-20261030-014143`。自动化场景均已退出。

偏离已授权目标：无；过程中依据实验调整实现，失败结果保留。剩余事项：远距离快速横移/旋转的命中与测深精度仍不足；没有实现残缺装甲的像素级融合、姿态反投影引导找灯或多车独立轨迹池。本轮已有同车多板融合和多板检测增强，不能把它们宣称为上述能力。ROS、实车按用户安排留到仿真之后。
